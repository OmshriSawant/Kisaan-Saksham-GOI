# Kisaan Saksham GOI

Kisaan Saksham GOI is an Android application designed to provide real-time commodity prices for various agricultural products. The app retrieves price data based on a 10 kg unit from multiple locations across India, utilizing the `data.gov` API. This project is built using **Java** and **Android Studio**.

## Features
- Displays the latest market prices for agricultural commodities.
- Supports multiple locations across India.
- Fetches data from **data.gov** via an API.
- User-friendly search functionality.
- Clean and intuitive UI design.

## Technology Stack
- **Programming Language**: Java
- **Development Platform**: Android Studio
- **Data Source**: data.gov API
- **UI/UX**: XML, Material Design

## Supported Locations
The app provides commodity prices for the following locations:
1. North Tripura
2. Medak
3. Coimbatore
4. Tarntaran
5. Ludhiana
6. Gurdaspur
7. Ferozpur
8. Bhatinda
9. Amritsar
10. Kohima
11. Pune
12. Alappuzha
13. Mahasamund
14. East Godavari

## Installation
1. Clone the repository:
   ```sh
   git clone https://github.com/OmshriSawant/Kisaan-Saksham-GOI.git
   ```
2. Open the project in **Android Studio**.
3. Sync Gradle dependencies.
4. Run the application on an emulator or physical device.

## Usage
1. Open the **Kisaan Saksham GOI** app.
2. Use the search bar to find commodity prices by location.
3. View detailed pricing for various agricultural products.
